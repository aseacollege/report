# Report · 학교 업무보고 시스템

한글 문서 형태의 주간업무보고서와 과정운영 관리를 연결하는 웹 시스템을 개발하는 저장소입니다.

## 개발 기준

- 초기 버전에는 로그인·회원가입·계정 관리·인증 화면을 구현하지 않습니다.
- 한컴독스의 구성과 동작을 REA로 분석하고, 확인된 근거를 바탕으로 자체 기능을 구현합니다.
- 주간업무보고서 양식의 표·문단·쪽 구성을 편집할 수 있도록 개발합니다.
- 과정운영 신규 등록·기존 과정 수정은 조건부 입력 팝업으로 처리합니다.
- 저장된 과정 정보를 보고서 요약과 전체현황에 연결합니다.
- 문서·첨부파일은 지정한 Google Drive 폴더에 저장하는 기능을 후속 구현합니다.

저장 위치는 `config/storage.json`의 고정 Google Drive 폴더 ID를 사용합니다. 이 설정만으로 업로드 권한이 부여되지는 않으며, 실제 저장 연결과 서버 인증은 후속 구현 항목입니다. 인증 정보는 저장소에 포함하지 않습니다.

교직원은 URL에 접속해 로그인 없이 작성·저장하는 흐름을 사용합니다. Drive 저장은 서버가 사전 연결한 계정으로 처리하며, 교직원에게 Google 로그인이나 권한 동의를 요구하지 않는 것을 개발 기준으로 합니다.

## 현재 상태

첫 웹 앱 버전을 구현했습니다. 로그인 없이 작업공간 주소로 접속하며, 글자·문단·표 편집, 서버 자동 저장, Yjs 기반 공동 문서 동기화(약 3초 간격), 과정 등록·수정·현황 조회를 제공합니다. 문서와 과정은 작업공간별 Cloudflare D1에 저장합니다.

공유 버튼의 주소에는 작업공간 접근 키가 포함됩니다. 같은 작업공간 주소를 받은 사람끼리 문서와 과정 정보를 공유합니다. 기본 URL만 처음 열면 기기별 작업공간이 생성됩니다. 계정 로그인은 요구하지 않습니다.

HWP/HWPX 직접 열기·저장, 한글과 동일한 조판·붙여넣기, 전체 340개 단축키, 수식·변경 추적은 아직 지원하지 않습니다. 미지원 메뉴는 비활성으로 표시합니다. Google Drive 업로드 경로는 구현했지만 관리자 자격 증명이 없어 실제 Drive 저장은 미연결입니다. 서버 저장과 구분해 표시합니다.

## 개발 및 검증

Node.js 24 이상에서 `npm ci`, `npm test`, `npm run build`를 실행합니다. `node scripts/preview.mjs`는 로컬 SQLite로 미리보기를 제공합니다. 브라우저에서 작성한 실제 자료는 Git에 포함하지 않습니다.

Sites 배포는 `.openai/hosting.json`과 `drizzle/` 마이그레이션을 사용합니다. GitHub 저장소에도 같은 소스를 보관합니다. 초기 관리자 Drive 연결에 필요한 서버 환경 변수 이름은 `.env.example`에 있습니다. Drive 업로드는 고정 폴더 및 승인된 작업공간 해시에 제한합니다. 실제 값을 소스·브라우저 코드에 넣지 않습니다.
