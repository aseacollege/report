# Report · 학교 업무보고 시스템

한글 문서 형태의 주간업무보고서와 과정운영 관리를 연결하는 웹 시스템을 개발하는 저장소입니다.

## 개발 기준

- 초기 버전에는 로그인·회원가입·계정 관리·인증 화면을 구현하지 않습니다.
- 한컴독스의 구성과 동작을 REA로 분석하고, 확인된 근거를 바탕으로 자체 기능을 구현합니다.
- 주간업무보고서 양식의 표·문단·쪽 구성을 편집할 수 있도록 개발합니다.
- 과정운영 신규 등록·기존 과정 수정은 조건부 입력 팝업으로 처리합니다.
- 저장된 과정 정보를 보고서 요약과 전체현황에 연결합니다.
- 문서·첨부파일은 지정한 Google Drive 폴더에 저장하는 기능을 후속 구현합니다.

## 현재 상태

저장소 및 개발 기준을 준비한 단계입니다. 실행 가능한 웹 앱, 공동 편집, DB 및 Google Drive 연결은 아직 구현하지 않았습니다.
