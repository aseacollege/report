# 데스크톱 한글 단축키 기준

기준 제품: PC 설치 확인된 한글 2024(13.0.0.711). 아래는 [한글 2024 공식 단축키 일람](https://help.hancom.com/hoffice130/ko-KR/Hwp/view/toolbar/shortcut(table).htm)의 데이터 행 340개를 추출한 참조표다. 같은 기능의 문맥별 중복, 대체 키, 반복 누름과 마우스 병용 항목을 그대로 보존한다. 사용자가 별도 지정한 사용자 정의 단축키까지 의미하지는 않는다.

REA Evidence: `ev_a750e7c291f797865978967b4081e65ecc088b2e2d48f832e7435225b2ceedee`. 원본 응답 SHA-256: `89c63dede3ed0694c785a0955d0f798bd5b2a81b243dfc389b266b96c57f14f6`.

**수집 완료와 동작 구현 완료는 다르다. 모든 항목은 현재 미구현·실행 미검증이다.** 키만 가로채고 기능을 실행하지 않는 구현은 지원으로 표시하지 않는다.

## 입력 해석

- `Ctrl+N,T`: Ctrl+N을 누르고 뗀 다음 T를 누르는 순차 입력이다. 모든 키를 동시에 누르는 것으로 처리하지 않는다.
- `F3/F4→Alt+C`, `F5→Alt+C`: 먼저 선택 상태를 만들라는 문맥 조건이다.
- `F3, 2번`과 `F3, 3번`: 반복 횟수를 구분한다.
- `/`, 쉼표, `+`, `-`는 키 이름·대체 입력·설명에도 쓰이므로 단순 문자열 분할로 등록하지 않는다.
- 셀 블록의 M·S·H·W·A 등은 해당 선택 상태에서만 처리한다.
- Windows 한글 기본 키 구성을 우선하며, 웹에서 변형된 키는 원본 키를 대체하지 않는다.

## 브라우저 한계와 적용 규칙

일반 웹페이지는 Alt+Tab, 브라우저의 Ctrl+Tab·Ctrl+F4·Ctrl+N 등 일부 키를 안정적으로 수신하지 못할 수 있다. 실제 지원은 운영체제·브라우저별 시험으로 판정한다. 이런 키는 목록에 유지하되 대체 키나 메뉴를 제공하며, 모든 원본 키의 작동을 보장하지 않는다. OLE·외부 프로그램·OS 창 조작처럼 웹 편집기 밖의 기능은 별도 구현 가능성 검토가 필요하다.

편집 영역에 초점이 있을 때만 명령을 처리한다. 검색창·팝업·과정 등록 입력창에서는 일반 입력 및 해당 대화상자 키를 우선한다. 한글 IME 조합 중에는 서식·선택 명령이 조합 글자를 손상하지 않게 한다. 구현된 명령이 실제로 수락한 이벤트에만 기본 동작을 막는다.
