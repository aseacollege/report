# 첫 배포 버전

## 구현

- 한컴독스 조사에 기반한 9개 메뉴와 리본, A4 편집 화면, 확대·축소, 보고서 목록
- 글자·문단 서식, 표 삽입·셀 병합/분할·줄/칸 편집·열 너비 조절, 이미지 삽입, 찾기·바꾸기
- 전용 JSON 및 HTML 가져오기/내보내기, 브라우저 인쇄/PDF
- Yjs 문서 상태의 서버 병합, D1 버전 비교 후 갱신으로 동시 저장 충돌 재시도
- 공유 주소의 192비트 작업공간 키, 서버에서는 SHA-256 해시로 데이터 분리
- 과정 필수 입력·날짜·인원 검증, 등록/수정 구분, 낙관적 수정 잠금, 현황 검색
- 과정 요약은 당시 내용을 보고서에 삽입하며 이후 과정 변경으로 과거 보고서를 수정하지 않음
- 저장 실패 시 기기 임시 보관 및 재시도, 성공 응답 후에만 서버 저장 완료 표시

## 검증

- 자동화: 독립 작성자의 CRDT 병합 수렴, 실제 API 저장/동시 갱신/작업공간 분리, 과정 수정 버전 충돌, Drive 미연결 시 성공으로 오표시하지 않는지 테스트
- Chrome 로컬: 한글 입력, 저장 후 다른 창에서 열기, 다른 창의 추가 내용 반영, 과정 신규 등록/수정, 보고서 요약 삽입, 전체현황, 4×3 표 삽입, 표 안에서 Alt+L 설정창 호출
- 실행에 쓰이는 npm 의존성 보안 검사: 알려진 취약점 0건

## 제한

자동 쪽 조판과 한글 파일 호환·완전한 붙여넣기는 구현하지 않았다. 340개 데스크톱 참조 행 중 일부 기능과 키만 연결했다. Google Drive는 고정 폴더 업로드 코드까지만 준비했으며 서버 관리자 연결과 폴더 쓰기 검증이 필요하다. 공동 편집은 주기적 동기화로, 상대방 커서나 즉시 접속자 표시는 없다. 보고서 수정 이력 복원 UI는 없다.
