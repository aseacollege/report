# 요구사항

## 확정된 방향

초기 버전에는 로그인 체계를 구현하지 않는다. 학교 주간업무보고서 형태의 문서 작성 화면에 과정운영 등록·수정 및 전체현황 버튼을 둔다.

## 문서 화면

- 작성부서, 작성자, 검토자, 보고기간, 문서 상태
- 부서별 근태 현황
- 과정운영 영역
- 처리 완료 및 진행 중 업무, 추진 계획 업무, 안내사항
- 표·문단 서식을 갖춘 편집, 저장, 보고서 목록

## 과정운영

- 신규 과정 등록: 필수 항목을 확인한 후 새 고유 ID 발급
- 기존 과정 수정: 검색·선택한 ID의 값을 불러와 수정
- 입력 항목 후보: 과정명, 부서, 담당자, 시작일, 종료일, 인원, 상태, 보고 내용
- 종료일이 시작일보다 빠르지 않도록 검증하고 인원은 음수가 아닌 정수로 제한
- 저장한 과정 정보를 문서의 요약과 전체현황에 연결
- 과정의 최신 현황과 완료 보고서의 당시 기록 구분

## 저장과 공동 사용

- 관리 정보는 DB, 문서 및 첨부파일은 지정 Google Drive 폴더 저장을 목표로 한다.
- 저장 폴더 ID는 `1GS_Dk6cdXH7x1rbCRTBh7p-VJvkgh8D8`로 고정한다. `config/storage.json`을 저장 위치의 기준으로 사용하며 사용자에게 폴더 선택을 요구하지 않는다.
- Google Drive 연동을 위한 저장소 연결 자격 증명은 사용자 로그인 기능과 구분한다. 계정 및 연결 방식은 아직 정하지 않았다.
- 공동 편집과 수정 이력은 후속 개발 항목이다.
- 기존 학교 시스템의 API, 데이터 구조와 연결 권한은 아직 확인하지 않았다.

## 개발 순서

1. REA 편집 화면 분석 보완 및 문서 편집 기술 검증
2. 로그인 없는 보고서 편집·저장 화면
3. 과정 등록·수정 팝업, DB와 전체현황 연결
4. Google Drive 파일 저장 연결
5. 공동 편집 및 문서 호환 검증

기술 스택과 배포 환경은 아직 확정하지 않았다. HWP/HWPX 호환 수준은 실제 학교 양식으로 검증한다.
